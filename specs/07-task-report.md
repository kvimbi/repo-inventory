# TASK 07 — Markdown report

**Goal:** `core/report.ts` — render an `Inventory` as a single readable
`INVENTORY.md`, so the overview is usable without starting a server.

**File you create:** `core/report.ts`

**Files you must not touch:** everything else.

---

## Public API

```ts
import type { Inventory } from "./types.ts";

/** Renders the inventory as GitHub-flavoured markdown. Pure — no file access. */
export function renderMarkdown(inventory: Inventory): string;

/** Renders and writes <baseDir>/INVENTORY.md. Returns the path written. */
export function writeReport(baseDir: string, inventory: Inventory): Promise<string>;

/** Human-readable byte size, e.g. "1.4 GB", "820 KB", "0 B". */
export function formatBytes(bytes: number | undefined): string;

/** Human-readable age, e.g. "3d", "5mo", "2y", "—" for null/undefined. */
export function formatAge(days: number | null | undefined): string;
```

Keep `renderMarkdown` pure so it is trivially testable and reusable by the
frontend later if needed.

## Document structure

Produce exactly these sections, in order.

### Header

```markdown
# Code inventory

Scanned `<root>` at `<scannedAt in YYYY-MM-DD HH:mm>` — 53 projects in 12.4s.
Remote state: **stale** (no fetch) | **fresh** (fetched)
```

Use `inventory.fetched` to choose the remote-state wording. Being explicit about
staleness matters: every ahead/behind number below is only as good as the last
fetch.

### Summary

A markdown table of counts:

```markdown
## Summary

| Metric | Count |
|---|---:|
| Projects | 53 |
| Git repositories | 50 |
| Untracked project folders | 3 |
| Worktrees / submodules | 1 |
| Without a remote | 38 |
| With uncommitted changes | 12 |
| With unpushed commits | 4 |
| Stale (>180d) | 21 |
| Marked obsolete | 0 |
| Marked archived | 0 |
| Reclaimable build output | 14.2 GB |
```

Derive every row from `inventory.projects`. "Reclaimable" is the sum of
`disposableBytes`, formatted with `formatBytes`.

### Needs attention

```markdown
## Needs attention

Projects with at least one critical flag, worst first.

| Project | Kind | Stack | Last commit | Flags |
|---|---|---|---:|---|
| `tmp/studio_resco` | repo | node, python | 2d | **No remote** (412 commits, no remote configured) |
```

- Include only projects where `risk === 3`.
- `Project` cell: `` `relPath` ``.
- `Stack` cell: `stack` joined with `, `, or `—`.
- `Last commit` cell: `formatAge(lastCommitAgeDays)`.
- `Flags` cell: for each flag with severity `critical`, `**label**` followed by
  `` (detail) `` when a detail exists. Join multiple with `<br>`.
- Escape any `|` characters found in details, so the table cannot break.

### By group

One subsection per `group`, sorted alphabetically, `(root)` last.

```markdown
## By group

### tmp — 21 projects

| Project | Kind | Stack | Branch | Sync | Last commit | Size | Status | Flags |
|---|---|---|---|---|---:|---:|---|---|
| `aitrader` | repo | python | main | local-only | 3mo | 4.2 MB | unknown | LOCAL_ONLY, STALE |
```

- `Project` cell: the `relPath` with the group prefix stripped, in backticks.
- `Sync` cell logic, in this priority order:
  - no remote → `local-only`
  - `noUpstream` → `no upstream`
  - `ahead > 0 && behind > 0` → `↑{ahead} ↓{behind}`
  - `ahead > 0` → `↑{ahead}`
  - `behind > 0` → `↓{behind}`
  - otherwise → `in sync`
- `Size` cell: `formatBytes(sourceBytes)`.
- `Status` cell: `annotation.status`, plus `` (snoozed) `` when
  `annotation.snoozedUntil` is in the future.
- `Flags` cell: rule names joined with `, `, or `—` when there are none. Omit
  `HEALTHY` from this list and render a `healthy` marker instead.
- Suffix a note line under the table when any project in the group has a
  non-empty `annotation.note`:
  ```markdown
  > `aitrader` — needs a rewrite before it is useful
  ```

### Footer

```markdown
---
Generated by repo-inventory. Probes: git-basics, git-fetch, … · Rules: 19 · Actions: 4
```

## Formatting helpers — exact behaviour

### `formatBytes`

- `undefined` → `"—"`
- `< 1024` → `"<n> B"`
- Then `KB`, `MB`, `GB`, `TB` with **one** decimal place, e.g. `"1.4 GB"`.
- Use 1024 as the divisor.

### `formatAge`

- `null` / `undefined` → `"—"`
- `0` → `"today"`
- `< 31` → `"<n>d"`
- `< 365` → `"<n>mo"` where n is `Math.round(days / 30)`
- otherwise → `"<n>y"` where n is `Math.round(days / 365 * 10) / 10`, e.g. `"1.4y"`

### `writeReport`

Write `<baseDir>/INVENTORY.md` with `node:fs/promises` `writeFile`, utf8, ending
in a single newline. Return the absolute path.
